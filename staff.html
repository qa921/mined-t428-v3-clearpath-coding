How invoicing works

  1. Type the student name and choose the program. The price shown is the stored tax-inclusive price — tax is never added again.
  2. Attach one approved payment proof. Revoked or pending-review proofs cannot be used, and each proof can be linked to only one invoice.
  3. Create the invoice, then download the branded PDF. Screen, list, API and PDF all show the same amount with the note “Price includes applicable tax”.
  4. We never collect or invent student email addresses, and no student accounts are created here.
